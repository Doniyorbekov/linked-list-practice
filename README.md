# Linked List Practice

A small Python project for practicing singly linked lists and basic algorithms.

## What I practiced

* Creating nodes with a `Node` class
* Connecting nodes into a linked list
* Traversing a linked list
* Searching for an element
* Counting nodes
* Finding the maximum and minimum values
* Calculating the sum of values
* Counting occurrences of a target value
* Deleting a node

## Example

The program creates the following linked list:

`10 -> 25 -> 7 -> 25 -> 17`

It then performs several operations such as searching, counting, finding minimum and maximum values, calculating the sum, and deleting a node.

## Technologies

* Python 3
